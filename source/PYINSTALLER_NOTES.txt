PyInstaller native build notes - TLO v1.7 Build 624
==================================================

TLO ships a restricted, source-built, audio-only FFmpeg 9.0.2 binary.
prepare_ffmpeg.py verifies the pinned upstream source archive hash, builds
FFmpeg for the *native host* architecture, checks the compiled binary and
stages it under tlo_ffmpeg_bin/ffmpeg[.exe] for PyInstaller.
The shared source archive may arrive from the separate GitHub Build Process's
verified Ubuntu acquisition step; the platform builder re-verifies its hash.
No prebuilt FFmpeg static release asset is downloaded or trusted.

The runtime resolver uses only the packaged FFmpeg and does not consult PATH,
IMAGEIO_FFMPEG_EXE, conda or a working-directory executable. Missing or
out-of-bundle FFmpeg is treated as an error, never a PATH fallback.

Build environments are pinned by requirements-build.txt. Install with
--require-hashes and --only-binary=:all:. The platform runner uses CPython
3.13.16, PyInstaller 6.22.3 and the source-hash-pinned FFmpeg build recipe.
Native build receipts, validation, security scans, signing, and distribution
are handled by the independently versioned GitHub Build Process v123.

Build 623 SHN-to-FLAC conversion relies on FFmpeg's pcm_s32le decoder/encoder
and raw PCM muxer, which are explicitly enabled by build_audio_ffmpeg.sh.
If strict decoding, independent PCM verification, or native Trash fails,
the converter retains the original SHN instead of destroying evidence.
