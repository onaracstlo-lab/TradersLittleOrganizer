TLO v1.7 Build 610 — LOCAL REGRESSION RESULTS — 2026-11-04

Root cause of GitHub Actions 41834899059:
- In the separate FFmpeg source job, all five original download attempts
  reached connection failures/timeouts across ffmpeg.org and www.ffmpeg.org.
- The hash check did NOT fail; no complete source archive was acquired.
- The workflow had no persistent source cache between independent CI runs.

Fix:
- Restore/save a content-addressed GitHub Actions source cache keyed to
  the original immutable FFmpeg 9.0.2 SHA-256 pin. The cache action is
  pinned to a full immutable commit SHA and marked continue-on-error so
  cache-service outages do not prevent the regular source retrieval path.
- After a cache miss, try ffmpeg.org, www.ffmpeg.org and
  mirrors.omnios.org/ffmpeg source tarballs in a bounded six-attempt
  round-robin. Timeout is 25 seconds of socket inactivity; backoff
  is bounded. Each candidate must match the original SHA-256 pin.
- Invalid cached bytes fail closed. Download hash mismatches, permanent
  HTTP errors and TLS certificate errors are not retried or accepted.
- Retain one shared, independently SHA-256-verified CI source artifact.
  Windows, Linux and macOS continue to compile offline from it; no
  upstream download in native build jobs.
